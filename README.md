# TMDB CLI

Uma aplicação CLI escrita em C para interagir com a API do TMDB (The Movie Database).

## Status
Atualmente, o projeto encontra-se em fase de desenvolvimento.

## Tecnologias
- **Linguagem:** C (Padrão C17)
- **Compilador:** GCC
- **Rede:** `libcurl`
- **Parsing JSON:** `cJSON`
